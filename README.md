# Delanta 德蘭塔

HD-2D 像素風網頁遊戲，改編自 MUD《Delanta》與原版 EnvyMUD 世界。

原始的《Delanta》MUD 寫於 **1996 年**——作者還在念高中的時候，當年以 EnvyMUD 為底子改編，作者親手做了中文化，並加入了 OLC（線上創造系統）。30 年後的 2026 年，再把它重新改版成這款 HD-2D 網頁遊戲。

## 玩法

**線上直接玩**：[https://doragonia332.github.io/delanta-game/](https://doragonia332.github.io/delanta-game/)（GitHub Pages，免安裝）

或下載後用瀏覽器打開 `index.html` 即可遊玩。

- 移動：方向鍵 / WASD / 手機虛擬方向鍵
- 互動：點選畫面物件，或在下方輸入列打 MUD 指令（`kill`、`say`、`gossip`、`inventory`、`equipment`、`score` 等原版指令）
- 戰鬥為即時制，含弱點破防、技能、道具與裝備畫面
- 多人：WebRTC 連線同房共鬥（房號或手動代碼），支援繁中 / English / 日本語 / 한국어 介面切換

## 世界

- 德蘭塔原創區域：怪奇森林、冥河、德蘭塔村（出自原作 MUD）
- 接合原版 EnvyMUD stock 世界：4,000+ 房間、1,200+ 怪物，房間描述與配置照原版 area 檔

# Delanta (English)

An HD-2D pixel-art web game adapted from the MUD *Delanta* and the original EnvyMUD world.

The original *Delanta* MUD was created in **1996**, when the author was in high school. Built on EnvyMUD, it was localized into Chinese by the author, who also added OLC (Online Creation). Thirty years later, in 2026, it has been remade as this HD-2D web game.

## How to play

**Play online**: [https://doragonia332.github.io/delanta-game/](https://doragonia332.github.io/delanta-game/) (GitHub Pages, no install needed)

Or download the repo and open `index.html` in a browser.

- Move: arrow keys / WASD / on-screen D-pad on mobile
- Interact: click objects on screen, or type original MUD commands in the input bar (`kill`, `say`, `gossip`, `inventory`, `equipment`, `score`, and more)
- Real-time combat with a weakness/BREAK gauge, skills, items, and a full equipment screen
- Multiplayer: WebRTC co-op battles in the same room (room code or manual code exchange); UI in Traditional Chinese / English / Japanese / Korean

## The world

- Original Delanta areas: the Strange Forest, the River of Death, and Delanta Village, from the original MUD
- Connected to the stock EnvyMUD world: 4,000+ rooms and 1,200+ monsters, with room descriptions and layouts faithful to the original area files
